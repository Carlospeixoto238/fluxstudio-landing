# Flux Studio AI Landing Page

Esta pasta é uma homepage separada do aplicativo principal.

- O app continua em: https://fluxstudio-app.onrender.com
- A landing usa os vídeos salvos em `assets/videos`
- O botão principal leva o cliente para o app funcionando no Render
- Nenhuma parte de Pix, login, créditos ou geração foi alterada aqui

## Publicação segura

Para colocar no domínio `fluxstudioai.com.br`, publique apenas esta pasta como site estático. Depois a homepage pode apontar para o app pelo botão "Entrar no App".

Quando o app estiver mais estável, dá para planejar uma migração com subdomínio, por exemplo:

- `fluxstudioai.com.br` para a homepage
- `app.fluxstudioai.com.br` para o aplicativo
