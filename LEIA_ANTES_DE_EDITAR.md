# Leia antes de editar

Este projeto e somente a landing page/homepage publica do Flux Studio AI.

## Regra principal

Nunca editar o app principal a partir deste projeto.

## Pode editar aqui

- `index.html`
- `styles.css`
- `robots.txt`
- `sitemap.xml`
- arquivos dentro de `assets/`
- textos, imagens e videos da landing

## Nao editar daqui

- `server.js`
- webhook do Mercado Pago
- creditos
- login
- geracao de videos/imagens
- banco de dados
- configuracao do Render do app
- qualquer arquivo do repositorio `fluxstudio-app`

## Estrutura correta

- App principal: `fluxstudio-app`
- Landing/homepage: `fluxstudio-landing`
- Dominio principal: `fluxstudioai.com.br`
- Botao "Entrar no App": `https://fluxstudio-app.onrender.com`

## Antes de publicar

Confirmar que a alteracao esta somente neste projeto da landing.

Se alguma tarefa pedir mudanca no app principal, pare e peca autorizacao explicita ao Carlos antes de continuar.
